# 运维控制台

运维控制台（ai-dashboard）面向集群管理员，提供用户与用户组、弹性配额、节点、工作负载和集群监控等管理能力。

- [部署指南](operations-console-deploy-guide.html) — 安装运维控制台及 Grafana，并配置认证和 Prometheus 数据源
- [功能使用指南](operations-console-user-guide.html) — 管理用户、配额、节点和工作负载
