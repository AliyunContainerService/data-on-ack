# AI套件控制台

AI 套件控制台提供面向平台管理员和研发用户的 Web 前端，用于管理集群资源、开发环境、训练任务和推理服务。本分类介绍控制台相关的安装、使用与运维能力；Notebook、Ray 等主题分别收录在对应分类中。

本部分包含以下分类：

- [运维控制台](operations-console.html) — 面向集群管理员的用户、配额、节点、工作负载和监控管理能力
- [开发控制台](development-console.html) — 面向研发用户的 Notebook、训练任务、模型推理和数据集管理能力
- [运维指南](ops-guide.html) — 两个控制台的升级、扩缩容、故障排查和安全加固
